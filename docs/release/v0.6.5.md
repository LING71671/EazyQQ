# EazyQQ 0.6.5 候选说明

本版本当前仅为本地候选，尚未建立公开发布或替换用户安装。

## 主要变化

1. 群聊人工发送正确传递会话类型；保存与发送失败可见，失败保留编辑内容。
2. 会话切换后旧历史、AI 候选和发送结果不再覆盖新会话；规则局部返回不丢弃原字段。
3. 免费检测支持停止、历史证据区分、账号私有目录清理和关闭窗口前的检测进程回收。
4. 更新记录覆盖检查至部署，主程序安装结果与真实目标版本启动分别核验，历史有界且只读查询。
5. 桌面、CLI 和 MCP 统一诊断与按故障恢复；包含前期未公开的更新历史与可选 Sentry 接入。

## 兼容与验收边界

账号、数据库、配置、缓存及进程所有权边界保持。真实消息发送与自动回复规则不因本候选测试而启用。原生验收使用隔离模拟协议，不能代替正式发布所需的全部安装与真实 QQ 加载证据。

安装程序退出 0 只表示安装程序成功退出；核心文件已部署也不证明活跃协议已加载新版。硬退出后没有最终回执的任务显示结束状态未确认，不根据时间猜失败。更新写入最多保留 100 条自有回执，全部未决时拒绝新任务；查询最多返回 50 条。

自然人设、多气泡 QQ 原生表情、任务独立 AI 会话和成员感知的智能体仍为增长设计，不宣称已经实现。完整结果与日志见 [本轮开发记录](../development/2026-10-28-reliability-and-lifecycle.md)。
