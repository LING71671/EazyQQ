# EazyQQ 0.6.6 发布说明

本版本面向 Windows x64 桌面端、独立 CLI 与 stdio MCP。安装包包含桌面端与同名 CLI，CLI ZIP 另提供 `ezq.exe` 兼容名。

## 主要变化

1. 号主自己发出的历史消息不再被算作对方来信；群成员使用稳定编号，引用与转发保留原始来源和消息编号，同一段输入不会重复进入上下文，重复短句也不会被当成噪声删除。
2. 会话请求带上实际的图片与受限文档正文；材料确实没读到时明确说明未读取，不从文件名或占位符编造内容。
3. 新增按账号隔离的本地聊天风格包：导入、切换、启停、导出与移除，V2 由语料分析生成条件画像，并区分训练与留出集。风格包只影响措辞，不提供身份事实，也不授予发送权限。
4. QQ 原生表情与同条文字可以混排；目录含 407 项有公开来源的编号，偷感、吃糖等动态表情在桌面端以真实 APNG 预览。
5. 新增 DeepSeek 官方、NVIDIA 与 AMD 开发试用预设，OpenCode 推荐顺位后移；供应方凭据按来源隔离，已保存的中转站模型、端点与 Key 保持原样。

## 兼容与边界

- 风格包 V2 需要 0.6.6 程序；既有 0.6.5 安装包不认识 V2 格式，也不会包含本轮任何增量。升级不迁移或删除账号数据库、配置、缓存与聊天记录。
- 私人风格包、语料分析报告与逐例决策只在本机忽略目录，不进入安装包、CLI ZIP、发布附件或公开说明。
- 不探测用户所选模型是否支持图片等多模态输入；不支持时按普通文本请求处理并说明未读取图片，不静默切换模型。
- 不默认启用接管规则。自动回复、草稿发送和群规则仍需用户逐项开启，安装或升级不改变既有开关。
- 模型预设只提供端点与默认模型名，不等于实时免费额度、也不保证全部模型可用；免费名单会变化，以设置页的检测结果和时间为准。
- 多气泡批次、任务型智能体和真实模型回复的真人盲评仍在后续范围，不在本版本内。

## 验收说明

桌面与 CLI 共用同一后端服务；本轮以 Rust/CLI 单测、前端与本地分析工具测试、类型与契约检查、正式 release 二进制的 CLI smoke、真实 Tauri 加模拟协议的原生验收为证据。原生验收不触碰真实 QQ、不需要手机登录。真实 QQ 中的表情外观与模型生成效果由用户按需自验，未计入本版本的自动化证据。
