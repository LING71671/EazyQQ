# EazyQQ 0.5.0

此版本集中修复登录、身份诊断、免费模型调用和恢复逻辑，并完成多账号与 CLI 的统一服务架构。

## 主要变化

- 多账号独立配置、端点、数据库、模型会话、浏览器缓存和消息工作进程；支持批量登记、启动、登录、停止及目标账号扫码。
- 快速凭据失效保留当前会话，确认目标身份后才切换；状态、诊断和 CLI 使用一致的身份校验。
- OpenCode 免费模型通过原生运行时调用；周期诊断不请求推理，一键恢复不批量结束 QQ。
- 完整 CLI 覆盖与生成接口规范、稳定 JSON / MCP 输出、发布资产校验和。
- 分层目录、中文开发记录及中文产品、架构、交互、接口、贡献和发布文档。

界面统一按钮、页面和抽屉的动效时长，支持系统减少动态效果偏好，隐藏窗口时暂停循环指示；移除固定启动等待与正常状态闪烁。README 改为产品展示首页，社媒宣传图重新设计。

## 下载

普通桌面用户选择 `EazyQQ_0.5.0_x64-setup.exe`；CLI 用户选择 `eazyqq-cli-windows-x64.zip`。安装包内也提供独立 CLI。`SHA256SUMS.txt` 和 `latest.json` 可用于校验资产。

需要 Windows x64 与官方 QQNT；使用免费模型需安装原生 OpenCode。QQ 凭据失效仍可能要求手机扫码；模型可用性以当前服务和显式测试为准。忘记账号保留本地数据，已有外部 QQ 会话不纳入 EazyQQ 的进程终止范围。

详细变化见仓库 CHANGELOG.md，维护和验收证据见 docs/development/。
