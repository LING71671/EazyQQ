# EazyQQ v0.5.5

修复 QQ 启动时找不到 `loadNapCat.cjs`、协议无法就绪的问题。

- QQ 加载器、目录桥和监督进程使用最终物理路径，避免虚拟化 AppData 的调用者与 QQ 使用不同目录视图。
- 主程序更新助手同样解析实际安装包、工作目录与交接文件，保留原有 SHA256 和大小校验。
- 启动诊断新增尝试编号、加载器执行和模块导入凭证；只读诊断不会触发登录、重启或 AI 推理。
- 修复旧账号状态响应在切换后回滚目标的竞态；选择目标时旧进程的数据绑定保持不变，等待新上下文重建。
- 保留多账号数据与现有 QQ 会话。登录态和内存策略仍留待下一阶段讨论。

隔离真实 QQ 已验证用户目录和 Program Files 两种跨盘布局的模块加载、WebUI 可达与无错误弹窗；该验收不代表账号已登录。新版本安装与分发验证结果见中文开发记录。
