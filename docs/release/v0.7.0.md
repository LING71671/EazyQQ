# EazyQQ 0.7.0 发布说明

本版本面向 Windows x64 桌面端、独立 CLI 与 stdio MCP，交付独立任务、人设继承、多气泡计划和可靠回执。分发产物及来源以本标签的发布工作流、`latest.json` 与 `SHA256SUMS.txt` 为准。

## 主要变化

1. 新增独立任务工作台。每个任务固定账号与会话，保存自身历史、会话代次、执行步骤和来源，支持继续、取消及完成后的候选转入草稿审核；同目标的不同任务不共用 AI 会话。
2. 新增有界工具流程。智能体可以检索本会话已验证缓存、列出当前群缓存目录、读取明确选择且已经下载文件的受限正文，并在获准时整理本任务待办；创建任务不触发推理，执行有调用数与时间预算。
3. 新增分层表达偏好。账号、好友、群、具体群成员依次继承，任务可追加自身偏好，清除后恢复上层；成员使用稳定 QQ 号码，表达偏好变化参与旧结果失效判断。
4. 新增有类型的多气泡计划和逐条草稿编辑。纯文字、纯 QQ 原生基础表情、同条混排和连续多条均支持；旧文字草稿兼容为单条，换行不自动拆消息。
5. 回复采用持久化批次和逐条平台回执。重试跳过已送达部分，明确失败和送达未知分开；未知项须核对后继续，新消息、撤权或旧计划失效停止剩余发送。普通推理请求使用独立自有目录，缓存保留有容量边界。

## 使用入口

桌面侧栏打开“任务工作台”，选择会话并创建任务，点击执行后查看记录和来源。需要文件正文时，先在群文件页明确下载，再选择本任务允许读取的文件。完成后的候选使用“转入草稿”，在“草稿审核”逐条确认。表达偏好位于“系统设置”，支持保存当前层和恢复继承。

CLI 新增 `tasks`、`personas` 与 `reply-batches`，MCP 对应 `manage_tasks`、`manage_personas` 与 `manage_reply_batches`。详细字段、状态、容量和示例见[任务与回复契约](../api/TASKS.md)；以当前程序 `schema --json` 和 MCP `tools/list` 为实际入口。

## 兼容与边界

- 保留 0.6.6 的消息来源、多模态正文、407 项 QQ 原生 face 目录、风格包 V1/V2 与供应源预设；私人风格包、聊天语料和分析报告不进入公开资源。既有 0.6.6 安装包不含本轮新增能力。
- 首版每次任务最多 6 次模型调用、90 秒；最多选择 5 个已下载群文件，每个不超过 8 MiB、提取正文最多 20000 字符。缺少材料、类型不支持或超限时明确显示原因，不保证所有 PDF、音视频或文件均能提取。
- 不开放任意 Shell、浏览器、文件系统、跨会话检索、自动下载或外部待办同步。任务内部工具不能直接发送 QQ，表达偏好和材料不能扩大权限。
- 消息接管和发送仍受既有账号、会话与规则授权约束，安装或升级不自动开启规则。未知送达的核对依赖用户确认及平台消息编号，不承诺数据库与 QQ 之间绝对一次送达。
- 登录保持、按需资源策略、长期记忆和真人盲评不在本版新增范围。异常遗留目录和未决回执按所有权与容量保留，不为清理空间删除运行中任务或未决动作。

## 验收与公开状态

本轮使用隔离 `.test-runtime`、模拟模型和模拟协议验证任务、来源版本、取消、授权与逐条投递；真实 Tauri/WebView、实际 IPC 和账号私有 SQLite 用于界面与明暗主题验收。不调用用户真实模型，不向真实 QQ 发送测试消息，不把模拟证据写成用户模型效果或真实客户端表情外观已验证。

具体最终测试结果、产物、工作流与发布后核验由[本轮开发记录](../development/2026-10-30-task-replies.md)记载。桌面安装包、CLI ZIP、独立可执行文件、`SHA256SUMS.txt` 与 `latest.json` 按[发布流程](RELEASING.md)生成并核对；正式下载以已核验的 GitHub Release 为准。
