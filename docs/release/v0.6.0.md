# EazyQQ v0.6.0

新增符合“下载安装 OpenCode 即可使用”定义的免费模型检测。

- 当前目录来自原生 OpenCode 刷新，零定价只作为候选，不根据名称后缀承诺免费。
- 显式检测使用独立配置和账号数据，移除用户 Key 环境变量，让原生运行时采用自己的匿名流程；逐个请求中性文本，验证时不发送 QQ 消息或自动授权工具。
- 显示检测时间、免凭据可用、额外条件、明确停用、目录移除和暂未确认；网络失败不会被当作下架，旧模型不自动替换。
- 桌面与 CLI 共用检测服务；CLI 支持候选目录、显式验证和 JSON 行进度。
- 修复账号选择保存时的短暂 Windows 文件占用及错误返回，包含安装目录别名诊断、已登录二维码查询等后续修正。

QQ 登录态及内存策略仍留待下一阶段讨论。本版本保留已有协议会话、账号数据与浏览器缓存。
