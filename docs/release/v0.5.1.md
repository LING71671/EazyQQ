# EazyQQ 0.5.1

此补丁修复 QQ 加载入口，并完善主程序与 NapCat 核心组件更新。

- QQ 入口改为账号私有的相对 `.cjs` 路径，跨盘通过私有目录桥接，不向 QQ 安装目录写加载器。
- 主程序只选择稳定版本的 Windows x64 桌面安装包；独立 CLI 不再混入候选。
- 主程序与核心包检查来源、大小及 SHA256，失败不安装，支持重试和跨进程任务互斥。
- 主程序显示下载进度，校验后退出、安装并重开；核心只选择官方 Shell 包，显示下载、校验和部署阶段，完成后刷新实际版本。
- 核心部署保留账号配置、缓存与回滚备份，运行中的协议会话会阻止覆盖。

选择 `EazyQQ_0.5.1_x64-setup.exe` 或 `eazyqq-cli-windows-x64.zip`。登录态常驻与按需 AI 内存策略留待下一阶段讨论，本补丁不实施该方案。
