# 独立任务、多气泡与可靠投递开发记录

## 起始状态与原因

用户要求把已经规划但尚未开发的能力落实。起点为干净的 `main@cc7ce80`；其他 AI 已完成并公开发布 0.6.6。本轮分支为 `codex/task-replies`，不覆盖已发布标签和资产，不改动私有聊天记录与风格包。

0.6.6 已有消息来源、多模态、基础 QQ face、风格画像 V2 和供应源预设。本轮聚焦 [10 月 29 日方案](2026-10-29-persona-agent-context.md) 中尚未交付的相邻链路：表达偏好继承、独立任务、有类型的多气泡候选、可靠批次发送和有界工具工作流。登录记忆策略、任意电脑操作及长期记忆扩展不在本轮范围。

## 实现与决策

| 能力 | 实际落点与行为 |
| --- | --- |
| 分层表达偏好 | `ai/runtime/persona_settings.rs` 按账号、会话、具体群成员继承；任务再追加自身偏好。GUI/CLI/MCP 可读写和清除，偏好版本进入真实推理并参与旧结果失效判断 |
| 独立任务 | `workflows/tasks/` 使用账号 SQLite 保存 Task、TaskSession、TaskRun、来源工具记录、本地待办和候选；事务认领、版本比较、租约恢复、取消与预算均由程序执行 |
| 有界工具 | 只检索本会话已验证缓存、当前群缓存目录、明确选择且已下载文件的受限正文，或更新明确允许的任务待办。候选可幂等转入审核草稿，不能直接发送 QQ |
| 多气泡与回执 | `workflows/replies/` 保存气泡/段顺序、计划、输入快照、会话租约、账号节流和逐条平台回执；`protocol/messaging/reply_workflow.rs` 供 GUI/CLI/MCP 统一调用 |
| 运行目录与界面 | 持久任务目录隔离，普通聊天/简报/文档/测试推理使用自有临时请求目录。任务工作台、逐气泡草稿编辑、未知送达核对及表达偏好设置均有真实控件，支持明暗主题 |

每次发送先保存计划；发出请求前再次检查身份、授权和来源版本。只在平台返回有效且未复用的消息编号后确认成功。明确拒绝和送达未知分别处理；已发送前缀不重发，未知项核对前也禁止用新批次绕过。新消息、撤权、取消或旧计划失效会停止剩余消息；原草稿及回执保留。

任务运行期间支持取消，仅中止本任务拥有的推理 Future/子进程，不结束 QQ 或其他任务。进程异常中断后按过期租约显示中断或未知，不猜测成功。任务历史来自本任务，换模型、端点或认证会轮换会话代次。生成结果不能覆盖更新的修订或任务状态；旧任务候选在原任务继续、取消或删除后不能发送。

OpenCode 的普通请求与流式请求都会隔离；显式 Key 和无 Key 模式均隔离其他账号或主机的 XDG 配置与缓存，清除已识别的 OpenCode、OpenAI、Anthropic 和 Google 环境 Key，供应方限制为 OpenCode，保留用户明确选择的当前供应方 Key。临时目录持有自有租约，结束后仅清理该目录；保留数量和缓存容量有上限，异常遗留不自动当作其他任务目录删除。

## 兼容边界

旧文本草稿按单气泡兼容，文字内换行不推断为多条消息。现有 CQ 基础 face 文本仍可编辑和发送；未知 face、商城表情、图片表情和 Unicode emoji 不伪装成可用基础 face。风格包安装和私有语料流程保持既有格式，公开源码不包含个人样例。

`ask --json` 增加 `replyPlan`，保留 `reply` 文本预览；聊天构思入口保持文本兼容，不会因生成候选而自动发送。`send_draft` 改为返回实际批次报告；部分成功继续保留草稿。`get_group_files(cachedOnly:true)` 仅读本地库，任务文件选择不会隐式同步群目录；原群文件页刷新保持既有行为。

完整请求字段、状态、容量与 CLI 示例见[任务与回复契约](../api/TASKS.md)。用户随后指定本轮发布为 0.7.0，清单与生成契约已统一升版，并执行完整发布流程；公开结果以发布记录为准。

## 验证证据

功能冻结后的 Rust 256 项库测试与 4 项 CLI 测试全部通过；前端 22 个文件、109 项测试通过；类型、契约、展示与生产构建通过。发布门禁另有 AI 分析器 31 项、发布驱动 11 项、407 项表情目录一致性全部通过。0.7.0 的正式二进制与原生验收见收尾发布记录。

本轮测试使用每进程 `.test-runtime`、回环模拟协议和模拟模型；不调用用户真实模型，不向真实 QQ 发送消息，也不启用用户自动回复规则。原生验收通过真实 Tauri/WebView、实际 IPC 和账号私有 SQLite 验证控件、来源、任务与明暗渲染，截图与 JSON 保留在对应临时验收目录。

0.7.0 正式 release 二进制复验：Rust 256 项库测试、4 项 CLI 测试通过；CLI 冒烟 55 项通过，版本返回 `0.7.0`，夹具为 `.test-runtime/cli-lfxen24p`。安装包已由 `pnpm tauri:build` 生成，版本与四份清单及生成 schema 一致。

真实 Tauri 完整流程于 `.test-runtime/native-profiles-u8ee90do` 通过，包括账号往返、独立浏览器缓存、迟到状态保护、模型健康、风格包来源与原生 face 预览。新增 `tasks-replies-ui.json` 确认任务固定账号创建/删除、不隐式推理、表达偏好保存及 IPC 重读、两条独立气泡、气泡内换行、单独 face 的离线标签、空气泡拦截、明暗主题实际样式变化，且 `realQQTouched=false,remoteModelsContacted=false`。界面截图已由主代理直接查看；暗色任务列表的选中项对比度在视觉复核中另行修正并复验。

暗色选中行改为不透明深蓝并明确标题颜色；新增对比度检查初次碰到主题动画中间帧，改为等待达到可读阈值。最终 `.test-runtime/native-profiles-iux0pzqz` 完整通过，选中标题实际对比度为 10.35:1，截图已直接查看。

## 首版明确限制

群文件任务只读取用户已下载并明确选择的文件；自动下载链路未向智能体开放。PDF、音视频或超限文件不承诺提取成功，错误会保留在步骤记录中。长期记忆、跨会话检索、外部待办同步、任意浏览器/文件系统/命令行工具均不开放。

未知送达的人工核对依赖用户确认和平台消息编号，不能证明数据库与 QQ 实现了绝对一次发送。异常退出后的临时推理目录可能保留，达到容量时明确停止新请求；不会为节省空间删除运行中的任务或未解决的外部动作回执。
