## 动效设计与实现

操作界面的动效解释状态与空间关系，不添加持续演出。按钮反馈约 120ms，抽屉进入 200ms、退出 160ms；页面切换只做短透明度调整。抽屉关闭后仍保留短退出阶段，但立即 inert，不能继续操作；快速重开会取消旧退出定时器。

移除启动固定 900ms 等待和正常状态持续闪烁；预加载和 React 启动层在减少动态效果模式下改为静态反馈。应用隐藏时暂停循环指示，重新显示后恢复；退出时更快淡出，不再固定保留 320ms。

共享 CSS 位于 `src/styles/motion.css`，将 transition-all 限定为颜色、透明度与变换，避免意外动画布局尺寸。抽屉以半透明遮罩替代全窗口模糊。`usePresence` 和 `useMotionPolicy` 管理关闭/重开及可访问性策略，不增加动画依赖。
