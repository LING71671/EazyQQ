# 0.5.5 修复交付

## 原因与边界

公开版本仍为 0.5.3。0.5.4 候选的安装、重装和单元测试通过，但完整门禁发现了真实账号切换竞态，没有公开 Release。保留 v0.5.4 标签，不强制更新；把跨进程物理路径、启动证据与账号选择竞态修复合并到 0.5.5。

原因与证据见 [物理路径记录](2026-10-09-physical-path-handoff.md)、[0.5.4 候选记录](2026-10-09-release-0.5.4.md) 和 [账号竞态记录](2026-10-09-account-selection-race.md)。已验证的隔离真实 QQ 模块加载不等于账号已登录；黑屏原因仍未确认，未修改驱动或系统安全配置。

## 当前验证

修复后的 Rust 为 120 项库测试和 2 项 CLI 测试，共 122 项通过。原生模拟协议延迟旧状态响应直到新目标保存后再释放，`delayedStatusSelectionPreserved=true`；账号往返、浏览器缓存、窗口和快捷键断言均通过，未操作用户 QQ。

0.5.5 清单、生成契约、中文产品/接口/架构/README/智能体文档统一。本地构建继续使用 A 盘缓存；完整构建、分发包校验、云端发布与本机升级结果待实际执行后追加，不能提前声称完成。

`pnpm tauri:build` 已生成 26706955 字节的候选安装包；`pnpm release:package` 生成六项分发资产，698 文件资源检查及 CLI 0.5.5 版本检查通过。原生验收再次返回 `delayedStatusSelectionPreserved=true`，发布 CLI 24 项冒烟通过。日志为 `.test-runtime/release-0.5.5-build.log`、`release-0.5.5-native.log`、`release-0.5.5-smoke.log` 和 `release-0.5.5-package.log`。
