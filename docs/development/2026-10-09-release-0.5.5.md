# 0.5.5 修复交付

## 原因与边界

公开版本仍为 0.5.3。0.5.4 候选的安装、重装和单元测试通过，但完整门禁发现了真实账号切换竞态，没有公开 Release。保留 v0.5.4 标签，不强制更新；把跨进程物理路径、启动证据与账号选择竞态修复合并到 0.5.5。

原因与证据见 [物理路径记录](2026-10-09-physical-path-handoff.md)、[0.5.4 候选记录](2026-10-09-release-0.5.4.md) 和 [账号竞态记录](2026-10-09-account-selection-race.md)。已验证的隔离真实 QQ 模块加载不等于账号已登录；黑屏原因仍未确认，未修改驱动或系统安全配置。

0.5.5 清单、生成契约、中文产品/接口/架构/README/智能体文档统一。本地构建继续使用 A 盘缓存；完整构建、分发包校验、云端发布与本机升级结果待实际执行后追加，不能提前声称完成。
