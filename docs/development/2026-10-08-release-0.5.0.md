# 0.5.0 发布开发记录

日期：2026-10-08。状态：本地发布验收和产物已完成，正在提交标签并执行 GitHub 自动发布。以下仅记录已验事实。

## 用户要求与范围

用户确认完成全部工作后发布 0.5.0，并要求所有项目文档改为中文，主要服务中国开发者。沿用此前的登录、多账号、CLI、模型、自愈和分层重构成果，保留原有未提交修改。不要求用户手动启动桌面或再次扫码。

## 发布准备

package.json、Cargo.toml、Cargo.lock、tauri.conf.json 和生成命令 schema 统一为 0.5.0。pnpm 版本从 packageManager 声明获得。版本检查同时检查 Cargo.lock 的自身包版本。

README、产品、设计、架构、接口总览、IPC、CLI、覆盖矩阵、开发记录、智能体指南和代理指引更新为中文；新增贡献指南、变更日志、发布流程与中文 Release 说明。JSON 字段、命令、代码和代码注释保持英文。

内置说明书删除失效的 OpenCode 4096 端口连接方案、不存在的快捷键及过度能力声明。F1 已补充为说明书开关；窗口控制前端返回类型与后端原始布尔/空值一致。

## 自动验收新增能力

`scripts/validation/native_profiles.py` 使用真实 Tauri 程序、两个模拟协议账号和独立根目录。没有真实 QQ 启动器，不需要手机。验证身份往返、私有 WebView 目录、localStorage 不串用、最大化还原、F1 与实际桌面版本。

先前未完成的缓存隔离已通过模拟协议原生补验。新版本完整原生验收将使用 0.5.0 Release 二进制再执行，不能仅依赖旧构建结果。

## 发布流程变更

发布工作流先校验标签、准备中性协议资源，执行类型、生成契约、前端、Rust、CLI 与原生回归；所有检查完成后才创建/公开 GitHub Release。使用 pnpm action，不再运行 npm install。

打包脚本生成桌面安装包、CLI ZIP、独立 CLI 及兼容别名、SHA256 和 latest.json。CLI ZIP 包含协议资源和中文文档。资源检查拒绝个人配置、凭据、缓存、SQLite、日志和符号链接；同步过滤大小写及 sqlite/sqlite3 扩展名。
