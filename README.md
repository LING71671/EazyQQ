# EazyQQ

> **零门槛、零命令行的个人专属 QQ 智能助手桌面端**  
> 基于 **Tauri 2 (Rust) + React 19 + Tailwind CSS + SQLite WAL** 架构，内置开箱即用的 NapCat (OneBot 11) 协议引擎，无需用户懂技术，连接官方 QQ 即可享受智能消息接管与会话摘要。

---

## ✨ 核心特性亮点 (Key Features)

### 1. 🛡️ 严格双重独立白名单（默认拒绝 Default-Deny）
- **绝不窥探隐私**：初始状态下所有好友与群聊均为「未白名单」，完全旁路静默，不记录任何聊天记录，不触发 AI 计算。
- **双白名单独立控制**：
  - **消息接管白名单**：可设为「草稿审核」或「自动秒回」；
  - **群消息总结白名单**：独立开关与周期，仅对目标群进行流水追踪与周期提炼。

### 2. ⚡ 小白全链路健康自愈体系 (v0.11)
- **内置 NapCat 零配置**：随安装包一键分发纯净运行核心（DLL、注入器与主脚本），普通用户只需电脑已安装官方 QQ，启动即可一键注入连接。
- **全链路 5 大节点实时嗅探**：随时监控 Windows QQ、NapCat 引擎、OneBot 通道、本地数据库及大模型连通性。
- **可视化自愈抽屉**：顶栏与登录页提供红黄绿状态灯，遇到断链时提供大白话排障指南与「一键重启协议服务」按钮，并支持一键导出脱敏诊断包 (`.zip`)。

### 3. 🧠 动态大模型探活与时段免费模型自适应
- **拒绝硬编码死角**：前端与后端接口实时探测 OpenAI 兼容端点的 `/models` 列表。
- **官方免费通道优先**：支持 OpenCode 开源官方免 Key 通道，自动识别带 `free`、`flash`、`zen` 标签的时段免费模型并置顶推荐。
- **全生态兼容**：无缝对接本地推理（Ollama、LM Studio、vLLM、llama.cpp）与各类商业大模型 API。

### 4. ✍️ 人机协同 AI 草稿箱（拒绝翻车）
- 白名单群收到提问或 @消息 时，自动生成带思考链的拟答候选草稿。
- 提供草稿箱可视化审核卡片：支持一键放行真实发送、输入额外补充指令微调重写，确保发出的每条消息准确可控。

### 5. 📊 定时群聊智能简报
- 配置驱动的灵活定时调度（支持 1h / 2h / 4h / 6h / 12h / 24h 及自定义分钟）。
- 自定义滑动回溯窗口，AI 智能过滤水群噪声与无意义刷屏，精准结构化提炼核心议题、达成共识与遗留待办事项。

### 6. 🍃 极简资源占用与绿色常驻
- 内存常驻控制在 ~45MB，毫秒级响应。
- 深度适配 Windows 系统托盘（最小化/关闭均缩入托盘后台静默运行），双击图标秒速唤起。

## 🚀 快速开始 (Quick Start)

### 系统前提
1. **Windows 10 / 11 (x64)**
2. 本机已安装官方腾讯 QQ 客户端（软件将自动通过 Windows 注册表或标准路径嗅探）

### 源码运行（开发者模式）
1. **安装依赖**：
   ```bash
   pnpm install
   ```
2. **启动本地开发联调**（前端热重载 + Rust 后端监听）：
   ```bash
   pnpm tauri dev
   ```
3. **构建生产安装包**（绿色 NSIS 安装程序）：
   ```bash
   pnpm tauri:build
   ```

## 🔧 常见排障与自愈指南 (FAQ)

- **Q1: 界面提示“未连接”或“未检测到 QQ”？**  
  点击顶栏心电图图标或状态徽标，打开「链路健康体检」抽屉。确保已启动官方腾讯 QQ 并登录，点击抽屉中的「一键重启协议服务」即可自动恢复。
- **Q2: 大模型回复提示网络超时？**  
  在「系统设置」中切换推理供应源为“OpenCode 官方免费通道”，点击「从接口动态获取可用模型」刷新当前可用的免费模型并一键应用。
- **Q3: 遇到疑难故障无法解决？**  
  在健康抽屉中点击「一键导出脱敏诊断包」，系统会自动生成 `.zip` 诊断日志，提供给技术支持排查。
